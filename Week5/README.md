# Week 5 Assignment

## Objective
Learn Apache Spark fundamentals and perform data cleaning, transformations, filtering and aggregation using PySpark DataFrames.

## Tasks Performed

- Created Spark Session.
- Created a sample dataset.
- Removed duplicate records.
- Handled missing values.
- Filtered records based on conditions.
- Renamed columns and modified data types.
- Performed aggregations using count(), sum(), avg(), min() and max().
- Applied groupBy operations.
- Implemented a complete data processing pipeline.

## Output

The assignment demonstrates how Apache Spark can be used for efficient in-memory big data processing and ETL workflows.
