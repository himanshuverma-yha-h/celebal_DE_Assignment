# Retail Intelligence Data Pipeline- Final Project

## Overview

This project was developed as the final project of my 8-week Data Engineering Internship at Celebal Technologies.

The objective of this project is to build a complete batch data pipeline for a retail company using Databricks and PySpark by following the Medallion Architecture.

The pipeline processes both historical and incremental datasets, performs data validation and transformation, creates business-ready Gold tables, and generates useful business KPIs for reporting and analysis.

## Medallion Architecture

The project follows the Medallion Architecture consisting of five layers.

### 1. Raw Layer
- Loaded historical and incremental CSV datasets.
- Stored the original data without any modifications.
- Maintained source data for backup and reproducibility.

### 2. Landing Layer
- Converted CSV files into Parquet format.
- Performed audit validation using record count checks.
- Verified successful ingestion before further processing.

### 3. Bronze Layer
- Converted Landing data into Delta format.
- Added ingestion metadata.
- Stored historical and incremental datasets separately.

### 4. Silver Layer
- Cleaned and transformed the data.
- Removed duplicates.
- Handled missing values.
- Applied business rules.
- Created standardized datasets.

### 5. Gold Layer
- Created Star Schema.
- Built Dimension tables:
  - Customer
  - Product
  - Date
  - Promotion
- Built Fact Sales table.
- Generated business KPIs.

---

## Business KPIs

### KPI 1 - Net Margin by Region
Calculated the net sales generated by each store location after applying discounts.

### KPI 2 - Average Order Value by Promotion
Compared promotion types to identify which campaigns generated the highest average order value.

### KPI 3 - Customer Churn by State and Loyalty Program
Analyzed customer churn across different states and loyalty program categories.

### KPI 4 - Product Quality Index
Measured average product return rates across product categories to identify products requiring attention.

### KPI 5 - Store Traffic by Hour
Analyzed transaction volume by day and hour to identify peak business hours.

## How to Open the Project

The complete Databricks project is provided as a `.dbc` archive.

To open the project:

1. Open Databricks Workspace.
2. Click **Import**.
3. Select `Retail_Intelligence_Project.dbc`.
4. Import the notebooks into your workspace.
5. Run the notebooks sequentially:
   - 01_Raw
   - 02_Landing
   - 03_Bronze
   - 04_Silver
   - 05_Gold_KPIs
